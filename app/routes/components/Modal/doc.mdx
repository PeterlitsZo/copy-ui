You can use the Modal component to display content in a modal overlay.
The code to render the Modal component looks like the following:

```tsx
const [isOpen, setIsOpen] = useState(false);

return (
  <Modal isOpen={isOpen}>
    <Modal.Overlay onClick={() => setIsOpen(false)} />
    <Modal.Content center shadow>
      {anyThingYouWantToRender}
    </Modal.Content>
  </Modal>
);
```

It contains two main sub-components: `Modal.Overlay` and `Modal.Content`. The
`Modal.Overlay` is used to render the overlay background, and the
`Modal.Content` is used to render the actual content of the modal (you can use
the `center` and `shadow` props to make it place properly and have good shadow).

It also provides a `Modal.Raw` sub-component that can render the modal but
without any default styling. See the section below for an example.
