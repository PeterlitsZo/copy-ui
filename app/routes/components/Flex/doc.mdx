I do not think use `Flex` everywhere is a good idea. Sometimes what you need is
just a simple CSS files (or tailwind classes). But it is also useful that you
just want a simple flex container and do not want to name any class for it
(simple flex container means it does nothing but just for layout) -- So `Flex`
is here.

If you are using tailwind, just use it directly.

## Examples

### With Different Justify and Align Items

<DocLayout.Live node={<Demo02 />} code={demo02SourceCode} />

You can use `justifyContent` or `justify` prop to set the `justify-content`
style (and values `start` and `end` are alias of `flex-start` and `flex-end`).

You can use `alignItems` or `items` prop to set the `align-items` style (and
values `start` and `end` are alias of `flex-start` and `flex-end`).
