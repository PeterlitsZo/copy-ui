## Examples

### With Scrollable Content

<DocLayout.Live
  node={<WithScrollableContent />}
  code={withScrollableContentSourceCode['index.tsx']}
/>

You can use the `Card.ContentInScrollArea` sub-component rather then the plain
`Card.Content` sub-component to wrap the content in a `ScrollArea` component.

This is useful when you have a lot of content that needs to be scrollable.
