## Examples

### With Different Variants

<DocLayout.Live
  node={<WithDifferentVariants />}
  code={withDifferentVariantsSourceCode['index.tsx']}
/>

We can use the `variant` prop to change the variant of the input. Now we
support two variants:

- `default`: The default variant.
- `filled`: The filled variant.

### With Left & Right Sections

<DocLayout.Live
  node={<WithLeftAndRightSections />}
  code={withLeftAndRightSectionsSourceCode['index.tsx']}
/>

We can use the `leftSection` and `rightSection` props to add a left and right
section to the input.

### With Disabled State

<DocLayout.Live
  node={<WithDisabledState />}
  code={withDisabledStateSourceCode['index.tsx']}
/>

We can use the `disabled` prop to disable the input.

### With Different Sizes

<DocLayout.Live
  node={<WithDifferentSizes />}
  code={withDifferentSizesSourceCode['index.tsx']}
/>

We can use the `size` prop to change the size of the input. Now we support five
sizes:

- `xs`: The smallest size.
- `sm`: The small size.
- `md`: The medium size.
- `lg`: The large size.
- `xl`: The largest size.

### With Different Widths

<DocLayout.Live
  node={<WithDifferentWidths />}
  code={withDifferentWidthsSourceCode['index.tsx']}
/>

You can use the `width` prop or its shorthand `w` prop to change the width of
the input.
