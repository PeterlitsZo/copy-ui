You can use the `CodeHighlight` component to render your code with syntax
highlighting. It is built on top of [shiki](https://github.com/shikijs/shiki).

The supported languages are listed in `highlighter.ts` file. The default
languages are only `typescript`, `tsx`, `markdown`, `scss` and `css` - very
useful for this website but not enough for your project. So feel free to add
more languages you need.

Interestingly to know, I use some hacks to make the `CodeHighlight` component
support the line highlighting, line numbers, etc.
