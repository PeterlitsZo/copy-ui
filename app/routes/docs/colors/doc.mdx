Copy UI initially used a color palette forked from [open-color][1], but it soon
proved insufficient for our needs. We expanded each color to have 20
variations — from light to dark — and aligned the hue across different colors for
the same variation level. This makes it easy to switch from grayscale to a
colorful palette. We also fine‑tuned the chroma of each color to be more
subdued, ensuring a better visual experience.

All colors are now available through the theme system.

## Usage

You can access colors through the theme:

```tsx
import { useTheme } from "@/components/CopyUiProvider";

function MyComponent() {
  const theme = useTheme();
  
  return (
    <div style={{ backgroundColor: theme.colors.blue["500"] }}>
      Blue background
    </div>
  );
}
```
