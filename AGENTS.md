# COPY-UI Agent Guide

## Project Architecture

- `tp/`:
  All component templates are stored here.
- `cli/copy-ui/`:
  The Rust CLI source code. It can be compiled into the `copy-ui` binary that
  embeds all templates from `tp/`.
- `src/`:
  Website/component source code, including code generated by `copy-ui` and other
  supporting code.
- `app/`:
  React Router routes and static documentation pages.

## Required Workflow For Template Changes

When making component/template changes, agents must follow this workflow:

1. Make changes under `tp/` first.
2. Compile the CLI binary in `cli/copy-ui/`.
3. Install the latest local CLI from `cli/copy-ui/`:
   - run `just install`
4. Run `copy-ui` to regenerate components from templates.
5. Run root-level code generation:
   - run `just codegen`

## Component Metadata Update Rule

After changing any component, agents must also:

1. Update that component's `CHANGELOG.md`.
2. Update the timestamp in that component's `index.ts` header comment.
3. And then `just codegen`.

## Git Commit Message Rule

When creating a Git commit, the message must follow this format:

1. Use one single-word commit type, such as `feat`, `fix`, or `chore`, followed
   by a colon.
2. After the colon, write a sentence describing the commit. The sentence must
   start with an uppercase letter and end with a period.

## Unit Test Policy

- Do not add, modify, or delete unit tests unless the user explicitly requests
  test changes for the current task.
- If tests are required for validation, prefer running existing tests only.
